# CNN + Wiener Filter (Khử nhòe hình ảnh)

### 1. Mục tiêu
* Xây dựng hệ thống khử nhòe hình ảnh (Image Deblurring).
* Kết hợp Wiener Filter và mạng nơ-ron tích chập (CNN) để cải thiện chất lượng hình ảnh.
* So sánh hiệu quả giữa ảnh bị nhòe, Wiener Filter và CNN + Wiener Filter.
* Ứng dụng Machine Learning/Deep Learning vào xử lý ảnh thực tế.

### 2. Input / Output
* **Đầu vào (Input):** Hình ảnh bị nhòe (Blur Image), định dạng RGB.
* **Đầu ra (Output):** Hình ảnh đã được khôi phục (Restored Image).
* **Dữ liệu huấn luyện:** Các cặp ảnh Blur và Sharp tương ứng.
* **Mô hình:** CNN kết hợp bộ lọc Wiener, sử dụng PyTorch để huấn luyện.

### 3. Evaluation Metrics / Criteria (Tiêu chí & Độ đo)
* **PSNR:** Đánh giá chất lượng ảnh khôi phục, giá trị càng cao càng tốt.
* **SSIM:** Đánh giá độ tương đồng cấu trúc giữa ảnh khôi phục và ảnh gốc, càng gần 1 càng tốt.
* **MSE:** Đo sai số bình phương trung bình giữa hai hình ảnh, càng thấp càng tốt.

**Kết quả thực nghiệm:**

| Phương pháp | PSNR (dB) | SSIM |
|---|---:|---:|
| Blur | 26.0938 | 0.7631 |
| Wiener Filter | 25.1743 | 0.7264 |
| CNN + Wiener Filter | 26.1177 | 0.7637 |

Nhận xét: CNN + Wiener Filter cho kết quả tốt nhất trong lần thử nghiệm, tuy nhiên mức cải thiện còn nhỏ.

### 4. How it works (Cách hoạt động)
1. **Tiếp nhận dữ liệu:** Đưa ảnh bị nhòe vào hệ thống.
2. **Tiền xử lý:** Chuyển ảnh thành tensor và chuẩn hóa dữ liệu.
3. **Wiener Filter:** Thực hiện khôi phục ảnh dựa trên đặc điểm tín hiệu và nhiễu.
4. **CNN:** Học các đặc trưng hình ảnh để hỗ trợ cải thiện kết quả khôi phục.
5. **Xuất ảnh:** Tạo hình ảnh sau xử lý.
6. **Đánh giá:** Sử dụng PSNR, SSIM và MSE để so sánh chất lượng ảnh.

### 5. Dữ liệu sử dụng
* **Tên Dataset:** GoPro Large.
* **Nguồn:** Bộ dữ liệu chuyên dùng cho bài toán khử nhòe hình ảnh do chuyển động.
* **Quy mô:** 2.103 cặp ảnh huấn luyện và 1.111 cặp ảnh kiểm tra.
* **Cấu trúc:**
  * Blur: Ảnh bị nhòe, dùng làm đầu vào.
  * Sharp: Ảnh rõ nét tương ứng, dùng làm dữ liệu mục tiêu.
* **Thực nghiệm:** Sử dụng 200 cặp ảnh huấn luyện, gồm 180 ảnh huấn luyện và 20 ảnh xác thực; đánh giá trên 1.111 cặp ảnh kiểm tra.
* **Công nghệ:** Python, PyTorch, NumPy, OpenCV, Scikit-image và Streamlit.
* **Tiền xử lý:** Ghép cặp ảnh, chuyển đổi tensor, chuẩn hóa và cắt ảnh theo kích thước đầu vào.
