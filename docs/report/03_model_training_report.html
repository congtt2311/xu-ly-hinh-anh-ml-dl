Huấn luyện mô hình chính: NAFNet

Cấu hình dưới đây lấy từ lệnh huấn luyện NAFNet của dự án; Wiener và DeblurGAN là mô hình so sánh, không phải mô hình chính.

Kiến trúc NAFNet

Width 32số kênh nền

2, 2, 4, 8encoder blocks
2, 2, 2, 2decoder blocks

Cấu hình huấn luyện trong mã nguồn

256 × 256crop train
0.001learning rate
AdamWoptimizer

Seed mặc định: 42. Checkpoint tốt nhất được chọn theo validation L1.
